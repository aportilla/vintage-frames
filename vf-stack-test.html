Showcase Integration example Component reference
direction column row gap system px pad

Top, right, bottom, left. The attribute is emitted in the shortest equivalent CSS shorthand — all four zero leaves it off. Inside a vf-window body leave pad alone: the window already insets 12.

align auto start center end stretch baseline

Cross axis. auto stretches down a column and centers across a row — but never resizes a fixed-size control (a button, a popup, a field). stretch is asked for by name and applies to everything.

justify start center end between

Main axis. Nothing to see unless the stack has slack to distribute — down a column that means giving it a height.

wrap inline width system px height system px

Both optional. A declared width is the size half of layout rule 3: the stack is whole by construction, and so is everything stretched inside it.

Add Up Down Remove Clear grow — the selected child takes the slack

Children keep their size otherwise: System 7 boxes don't squeeze, so the default is flex: 0 0 auto.

Load stage 60%

How much of the stage the box may fill — slack for justify across a row, and room for wrap to run out of.

Mark the stack Mark the children applyGridSnap()

The components pick their own scale (3 device px per system px, whatever the display) — this page never sets --vf-scale, so what you see is what a consumer's page gets.
